# كوين ستار

نسخة أولية كتطبيق ويب لتجربة ألغاز النجوم وإعداد صفحات جاهزة للطباعة.

## التشغيل

1. افتحي مجلد المشروع.
2. افتحي ملف `index.html` بمتصفح حديث (Chrome أو Firefox أو Edge).
3. اختاري حجم الشبكة والصعوبة، ثم استخدمي «لغز جديد» أو أنشئي مجموعة للطباعة.

## طريقة اللعب الحالية

- ضغطة واحدة على خلية فارغة تبدّل علامة X.
- ضغطتان متتاليتان تضعان نجمة.
- السحب عبر الخلايا يضع علامات X على عدة خلايا.
- تظهر تعارضات الصف أو العمود أو المنطقة أو تلامس النجوم مباشرة (بما في ذلك التلامس القطري).
- لا تلامس النجوم بعضها، كما في حركة الملك في الشطرنج.

## التوليد والطباعة

- الأحجام المتاحة: 6×6 إلى 20×20.
- يمكن توليد مجموعة من 1 إلى 100 لغز بالمقاس والصعوبة المختارين.
- «طباعة الكتاب / حفظ PDF» تفتح نافذة الطباعة؛ اختاري «حفظ كـ PDF» من المتصفح عند ظهورها.
- تنزيل الصور ينتج ملفات SVG متجهية عالية الدقة.
- صفحات الألغاز تسبق صفحات الحلول.

## ملاحظة تطوير

هذه بداية قابلة للتجربة. مقياس الصعوبة الحالي يعتمد على عدد النجوم المعطاة مع الحفاظ على حل واحد بحسب محرك التحقق؛ ويمكن تحسينه لاحقًا بتحليل خطوات الحل. واجهة التصدير الجماعي للصور قد تعرض تأكيد تنزيلات متعددة في بعض المتصفحات.
